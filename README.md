# Реализация Хеш-таблицы (HashTable)

Домашнее задание по теме "Хеш-таблицы".

## 📌 1. Класс HashTable
Реализован класс хеш-таблицы с использованием **метода цепочек** (chaining). 
Внутри создается список "корзин". При добавлении элемента мы вычисляем его хеш, 
находим нужную корзину и добавляем туда пару `(ключ, значение)`. 
Если два ключа попали в одну корзину (коллизия) — они хранятся в виде списка.

**Реализованные методы:**
* `insert(key, value)` — добавление или обновление элемента.
* `search(key)` — поиск значения по ключу.
* `delete(key)` — удаление элемента.

## 📌 2. Метод Resize
Метод `resize()` увеличивает текущий размер таблицы в 2 раза и пересчитывает 
индексы (перехеширует) всех существующих элементов, чтобы они правильно 
распределились в новой, более объемной таблице. 
Протестировано на таблице с начальным размером 5 и 10 добавленными элементами.

## 📌 3. Простая хеш-функция для строк
Функция `simple_hash(string)` вычисляет хеш строки, суммируя ASCII-коды 
всех её символов с помощью встроенной функции `ord()`.

## 📌 4. Словарь на основе хеш-функции
Класс `SimpleDict` использует вычисленные хеш-значения в качестве ключей. 
Он позволяет добавлять строки и искать их по исходному ключу.
